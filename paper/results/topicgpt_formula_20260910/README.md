# TopicGPT 公式补充评分

2026-09-10。用户要求核查指标定义变化的影响后执行；属于事后补充敏感性分析。当前 HMP 主指标、主表和原始预测均保留。这里没有运行 TopicGPT 建模系统，只使用其所核对的评分公式评价本项目已封存预测。

## 同一预测，替换评分公式

范围：两批云端、四数据集、五次拟合、每次六种方法，共240个 eligible test 评分位置、48个五次汇总。AG News 沿用799个合格测试文本；-1 仍作为一个共享预测分区参与评分，覆盖率单独报告。重复的 BERTopic 预测是两批复用的20次结果，不增加独立基线样本。

补充公式：`sum_c (n_c/N) * max_k [2*n_ck/(n_c+n_k)]`。直接提取本地 TopicGPT 的 `calculate_purity` 函数执行，并与独立标量公式在全部240个位置逐项比较。三个人工边界例子亦通过。来源和输入/输出hash见[manifest](manifest.json)。

原公式：先分别计算全局 purity 与 inverse purity，再取调和平均。原 HMP 和覆盖率均由同一预测重新算出，与原封存评分逐行一致。数值变化反映定义差异，不是系统行为改变。

## 排序与解释

- 相对 BERTopic：GPT-4.1 mini 仍是3/4份数据均值较高，MASSIVE较低；Luna由3/4变成4/4，变化发生在AG News。此处比较的是当前固定 BERTopic 配置。
- 相对匹配K的 KMeans：mini仍只在AG News较高。Luna在Bills从略低变成略高，在MASSIVE从较高变成较低；AG News仍较高，SIB-200仍较低。Bills差额仅0.000853，不应据此声称可靠或显著优势。
- 相对最终直接分配：均值高低方向全部保持，mini在MASSIVE、AG News较高，Luna只在AG News较高。图与固定参考分配没有获得普遍优势。
- 最终Hybrid相对初始Hybrid的均值方向保持：mini在Bills/MASSIVE略升、AG News下降、SIB-200不变；Luna仅Bills略升。测试覆盖率全部不变。
- 全部32个“最终Hybrid对三个主要对照或自身初始阶段”的均值方向比较中，3处变化，见[比较明细](comparisons.csv)。这不是对六种方法所有两两排序的完整统计。
- 变更公式后，分数可能上升也可能下降；以前的人工例子得到更高分，并不表示所有真实结果都会提高。SD是五次运行波动，没有进行显著性检验。

## 对论文的处理建议

保留已冻结 HMP 为主指标，把这次结果作为明确标注的补充敏感性分析，同时报告有利与不利的排序变化。它说明部分比较结论取决于指标定义；不能因为Luna变成4/4就事后把它升为唯一主指标，或只展示这一张表。

可以陈述：在补充的 TopicGPT 评分公式下，Luna版本在四份固定语料上的均值均高于既定 BERTopic 基线，而相对KMeans的排序仍随语料变化。这不证明领先 TopicGPT 系统，也不能直接比较TopicGPT论文分数，因为数据子集、生成与评分样本规则不同。
