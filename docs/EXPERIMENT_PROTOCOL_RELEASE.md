## 比较与复用

1. Hybrid 最终版，以及同次生成轨迹中的初始主题无残差版。
2. 对初始/最终主题各做直接余弦分配，不拒分。
3. BERTopic：复用经 hash 核查的原 20 组预测；同训练/查询向量、相同 UMAP/HDBSCAN/随机配置，与生成后端无关。重复展示不视作新的独立运行。
4. KMeans：n_init=10、random_state 为本次编号，K 等于本次最终生成主题数。重新计算本地对照，不使用 gold K。
5. 复用 Qwen/Qwen3-Embedding-0.6B 的文档向量，验证原输入 hash、npz hash、模型与编码设置。新主题重新编码；查询向量来自已核查的逐篇编码。冻结的缓存只读，不能静默重算。

云端与本地各按部署容量装包，看到的文本数量可以不同。此比较回答部署方案的实用表现，不把差异全部归因于生成模型本身。记录每轮实际输入比例、主题数、耗时、内存、格式重试、token usage 和费用。

## 评分与停止规则

全体合格测试文档 HMP 为既定主指标，覆盖率并列；ARI/NMI 为辅助，已分配子集指标作为条件诊断。保留 -1 共享分区的解释边界。不增加后验综合分数，不据结果改主指标、阈值或剔除差的一轮。

生成进程只读 inputs/，预测完成后封存 hash，再由独立评分进程读取 gold/。报告全部五次及均值/标准差，同时登记计划数、成功数、失败数。失败记录不隐去、不自动补一个更好的替代结果；如发现实现错误，开新修订号并写明受影响运行。
